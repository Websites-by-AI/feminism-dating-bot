Run locally

  1. Extract ZIP, then run npm ci (Node.js 20+).
  2. Copy .env.example to .env and configure DATABASE_URL.
  3. Set up PostgreSQL, then run npx drizzle-kit push.
  4. Run npm run dev and open the local URL.

Where to start

src/app/page.tsx contains the experience; src/app/api/ contains endpoints; src/db/schema.ts defines tables. Read AGENT_HANDOFF_B5.md in the ZIP for the full handoff.

Important: The coach is rule-based, not a live AI model. The site does not dispatch emergency help or run an active Telegram bot. No revenue/income data is collected. The archive excludes secrets, user data, database contents, and build output.
