## 🚀 How to Deploy Website to Cloudflare

### Option 1: Use Wrangler (Recommended)
```bash
# Install wrangler
npm install -g wrangler

# Login
wrangler login

# Deploy
cd cloudflare-site
wrangler pages deploy . --project-name=ancient-fire-1864
```

### Option 2: Use Cloudflare Dashboard (Easiest)
1. Go to: https://dash.cloudflare.com
2. Workers & Pages → Create → Pages
3. "Upload assets" → Direct upload
4. Upload the entire `cloudflare-site` folder
5. Click "Deploy site"
6. Website live at: `https://ancient-fire-1864.pages.dev`

### Option 3: Use the deploy script
```bash
./deploy_cloudflare.sh
```
